Política de privacidade

Atualizada em 26 de novembro de 2026

O Almanaque da Nova Era é um projeto independente e gratuito de consulta. Você não precisa de cadastro nem de login para usar o site, e o site não pede nome, e-mail nem qualquer outro dado pessoal.

O que o site mede

Para saber quais páginas ajudam mais gente, usamos o Umami (cloud.umami.is), uma ferramenta de medição de visitas. Ela registra de forma agregada as páginas vistas, o site ou a rede de onde veio o acesso, o navegador, o sistema operacional, o tipo de aparelho e a localização aproximada (país, região ou cidade). Segundo a documentação do próprio Umami, a ferramenta não usa cookies e não coleta dados pessoais que identifiquem o visitante.

Os links que publicamos nas redes sociais levam parâmetros no endereço (como utm_source=facebook). Eles servem só para saber de qual publicação veio o acesso.

Cookies

O site não grava cookies nem usa o armazenamento local do navegador. Se um dia passarmos a exibir anúncios ou a usar outra ferramenta que use cookies, esta política será atualizada antes e o site passará a exibir um aviso de cookies.

Serviços de terceiros

  • Google Fonts: as letras (fontes Barlow) são carregadas dos servidores do Google (fonts.googleapis.com e fonts.gstatic.com). Para isso, o Google recebe o endereço IP e dados básicos do navegador de quem visita o site, conforme a política de privacidade dele.
  • GitHub Pages: o site é hospedado no GitHub Pages. O GitHub pode registrar dados técnicos de acesso, como o endereço IP, para operar o serviço, conforme a política dele.
  • Umami: medição de visitas, descrita acima.

Redes sociais

O site tem links para perfis no X, Instagram, Facebook e Threads. Quando você usa essas redes, o tratamento dos seus dados segue as políticas de cada uma delas.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018), você pode pedir informações ou a exclusão de dados pessoais seus que estejam conosco. Como o site não coleta dados pessoais que identifiquem o visitante, em geral não há o que excluir, mas, se tiver dúvida, fale com a gente pelos canais da página Contato.

Mudanças nesta política

Esta política pode ser atualizada. A data no topo da página mostra a versão mais recente.
